# Rehab Connect

build a ready to deploy website for physiotherapy clinic. Where patients can fill quitionairre and submit their problems and reports. Search. for nearby physio(s) over this platform, book their time slots. Patients can access to demo vedios by the trusted doctors. Recovery and analytics dashboard for patients.



## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
